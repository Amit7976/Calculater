# 🧮 Basic Calculator

A simple and responsive **Calculator** built using **HTML**, **CSS**, and **JavaScript**.  
Perfect for quick calculations and for learning how to handle math operations and DOM manipulation in JS.

🌐 **Live Demo**: [Try the Calculator](https://amit7976.github.io/Calculater/)

---

## ✨ Features

- ➕ Basic arithmetic: Add, Subtract, Multiply, Divide
- 🔄 Clear and reset functionality
- 💻 Keyboard-friendly input
- 🎨 Sleek, responsive UI design
- ⚡ Fast and works completely in the browser

---

## 🛠️ Tech Stack

- HTML5  
- CSS3  
- JavaScript (Vanilla)
